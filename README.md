# BB_mobile_2

Мобильная 3D-игра «Центральный Ярнам» (three.js), горизонтальный экран.

## Файлы
- `index.html` — игра
- `hunter.glb` — модель охотника (18 МБ)
- `hunter.mp3` — музыка (9 МБ)
- `B.jpeg` — картинка стартового экрана

Все файлы лежат в корне, пути в `index.html` относительные.

## Запуск
- **GitHub Pages:** Settings → Pages → Branch `main`, папка `/ (root)`. Игра откроется по адресу `https://<ваш-логин>.github.io/BB_mobile_2/`.
- **Локально:** `python3 -m http.server 8000` в этой папке и открыть `http://localhost:8000`. Двойным кликом по файлу модель и музыка не загрузятся.

Для загрузки модели нужен интернет: GLTFLoader и декодер meshopt подгружаются с CDN.

## Управление
Сенсорный джойстик и кнопки на экране. На клавиатуре: T — развернуть модель охотника на 180°. Параметр `?flip=1` в адресе делает то же.
